개인정보처리방침

시행일: 2026년 11월 11일 · 대상: K-Stock 주식 자산 관리 앱 (Android 앱 com.stockmanager.prototype 및 PC 버전)

K-Stock은 개발자가 운영하는 서버가 없습니다. 입력한 데이터는 사용자의 기기와, 사용자가 연결한 경우 사용자 본인의 구글 드라이브에만 저장되며 개발자에게 전송되지 않습니다.

1. 처리하는 정보

정보목적저장 위치
앱 계정 정보 (이메일, 비밀번호의 해시값)앱 안에서 사용자 구분·로그인사용자 기기 안 (앱 내부 저장소 또는 PC의 data 폴더)
보유 종목, 매입 정보, 배당 내역, 분류, 화면 설정자산·배당 관리 기능사용자 기기 안
화면 공유 설정 (공유받는 사용자의 이메일과 권한)같은 기기·서버 안의 사용자끼리 화면 공유사용자 기기 안
구글 계정 이메일 주소구글 드라이브 연결 상태 표시사용자 기기 안

앱은 광고, 분석(애널리틱스), 위치, 연락처, 사진, 기기 식별자 정보를 수집하지 않습니다.

2. 구글 사용자 데이터 (Google API)

  • 앱은 사용자가 [구글 계정 선택해 연결] 또는 [구글 로그인으로 연결]을 눌렀을 때만 구글 계정에 접근합니다.
  • 요청하는 권한은 https://www.googleapis.com/auth/drive.file 하나입니다. 이 권한으로는 K-Stock이 만든 파일(kstock-sync.json)만 읽고 쓸 수 있으며, 구글 드라이브의 다른 파일은 보거나 바꿀 수 없습니다.
  • 구글에서 받은 정보는 동기화 기능에만 사용하며, 개발자를 포함한 제3자에게 전송·판매·공유하지 않고, 광고나 사람이 열람하는 용도로 쓰지 않으며, AI 모델 학습에 사용하지 않습니다.
  • K-Stock의 Google API 수신 정보 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 준수합니다.

3. 외부로 보내는 정보

  • 시세·배당·실적 조회: 종목코드만 야후 파이낸스, 네이버 증권, FunETF, 각 자산운용사 사이트에 보냅니다. 개인정보는 보내지 않습니다.
  • 구글 드라이브: 사용자가 연결한 경우 동기화 파일을 사용자 본인의 구글 드라이브에 저장합니다.
  • 클라우드 서버 연결(선택): 사용자가 직접 운영하는 서버 주소를 입력한 경우 그 서버와 데이터를 주고받습니다. 이 서버는 사용자가 관리합니다.

4. 보관 기간과 삭제

  • 데이터는 사용자가 지울 때까지 기기에 보관됩니다. 앱의 환경설정 → 사용자 삭제로 그 사용자의 데이터를 모두 지울 수 있고, 앱을 삭제하면 휴대폰의 앱 데이터도 함께 지워집니다.
  • 구글 드라이브 연결은 환경설정 → 기기 간 동기화 → 구글 드라이브 연결 해제로 끊을 수 있으며, 구글 계정 → 타사 앱 액세스에서도 권한을 취소할 수 있습니다.
  • 구글 드라이브의 kstock-sync.json 파일은 사용자가 드라이브에서 직접 삭제할 수 있습니다.

5. 보안

비밀번호는 원문이 아닌 해시값으로 저장합니다. 외부 통신은 HTTPS로 합니다. 동기화 파일은 암호화되지 않은 JSON이므로 본인만 접근하는 구글 계정에서 사용하세요.

6. 아동

이 앱은 만 14세 미만 아동을 대상으로 하지 않습니다.

7. 변경과 문의

이 방침을 바꾸면 이 페이지에 시행일과 함께 게시합니다. 문의는 GitHub 이슈로 남겨 주세요.

Privacy Policy (English summary)

Effective: November 11, 2026. K-Stock has no developer-operated server. Your data (app account, holdings, dividends, settings, sharing permissions) is stored only on your device and, if you connect it, in a single file kstock-sync.json in your own Google Drive. Nothing is sent to the developer. No ads, analytics, location, contacts or device identifiers are collected.

Google user data: the app requests only the drive.file scope, which lets it read and write files it created (the sync file) and nothing else in your Drive. Your Google account email is used only to show the connection status. Data received from Google APIs is used only for syncing, is not transferred to third parties, is not used for advertising or AI model training, and is not read by humans. K-Stock's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Market data requests send only stock codes to Yahoo Finance, Naver Finance and fund-company sites. You can delete your data in Settings → Delete user, disconnect Google Drive in Settings, revoke access at myaccount.google.com/permissions, and delete the sync file from your Drive. Contact: GitHub issues.
